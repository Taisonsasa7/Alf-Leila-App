# 🌟 تطبيق ألف ليلة وليلة (Alf-Leila-App) 🌟
### منصة دردشة صوتية عالمية وتحديات تفاعلية بمستوى هندسي يضاهي أكبر التطبيقات العالمية

تطبيق **ألف ليلة وليلة (Alf-Leila-App)** هو منصة دردشة جماعية وصوتية مدمجة بعوالم افتراضية ثلاثية الأبعاد (3D/AR)، مصممة لتقديم تجربة تواصل غامرة واستثنائية تجمع بين التراث الثقافي العربي الأصيل وأحدث ما توصلت إليه التقنيات البرمجية والهندسية العالمية.

---

## 🏗️ الهيكل المعماري والبرمجي للمشروع (System Architecture)

تم تقسيم المشروع إلى طبقتين متكاملتين تضمنان أعلى مستويات الأداء والأمان وسرعة الاستجابة:

### 1. طبقة السيرفر الخلفي (Asynchronous FastAPI Backend)
سيرفر حديث فائق السرعة مبني بلغة بايثون باستخدام إطار عمل **FastAPI** المعتمد بالكامل على البرمجة غير الحاصرة (Non-blocking Asynchronous I/O)، مما يسمح بمعالجة آلاف الغرف الصوتية وملايين المعاملات اللحظية بكفاءة استثنائية.

- **`core/` (طبقة الأمان العامة والإعدادات)**:
  - `config.py`: إدارة وتحميل متغيرات البيئة العامة والتكامل مع خدمات السيرفرات الأخرى بشكل آمن عبر `pydantic-settings`.
  - `security.py`: تشفير كلمات المرور باستخدام خوارزميات `bcrypt` المضادة لهجمات التوقيت وتوليد توكنز الـ JWT الآمنة، وتكامل مباشر مع محرك Agora RTC لبناء توكنز الصوت اللحظية.
- **`routers/` (طبقة المسارات والعمليات التفاعلية)**:
  - `auth.py`: نظام تسجيل الدخول والمصادقة (بالتكامل الاختياري مع Supabase) مع محرك توليد الصور الرمزية المجسمة (AI 3D Avatar Likeness).
  - `rooms.py`: نظام الغرف عالية الأداء بسعة تدريجية مرنة (8، 16، 25 مقعداً) مجهزة بـ `asyncio.Lock` لمنع تعارض حجز الكراسي، وإضافة كراسي الـ PK المخصصة للتحديات.
  - `gifts.py`: نظام الهدايا الجغرافية العربية (50 معلم أثري متميز) والمأكولات والمشروبات المجهزة بدورات هضم تفاعلية وفيزياء تميع وتناقص حجم الكتل (Eating Loops) على مدى 30 ثانية.
  - `avatar_store.py`: متجر الكساء والزينة المجهز بورشة حياكة وتفصيل مخصصة ثلاثية الأبعاد (Embroidery Workshop) لحساب الدوران والهبوط السينمائي للمركبات والثيمات والإطارات.

### 2. طبقة الواجهات التفاعلية (Responsive Flutter Multi-Platform Frontend)
تطبيق هجين فائق السلاسة والسرعة مبني بإطار عمل **Flutter** ومبرمج بلغة **Dart** لدعم التشغيل في 60 إطاراً في الثانية (60fps) على كافة الأجهزة (الأندرويد، الآيفون، الشاشات الذكية TV OS، الساعات الذكية، ونظارات الواقع المعزز AR Glasses) مع مواءمة تلقائية لجودة العرض والأداء (Multi-Platform Adapters).

## ⚡ الميزات والابتكارات الهندسية المطبقة

1. **نظام الغرف عالي الكثافة وكراسي الـ PK المتكاملة**:
   - إمكانية التدرج بسعة كراسي الغرفة (8، 16، 25 مقعداً) مع حماية المعاملات بذاكرة مشتركة آمنة.
   - وضع تحديات الفرق (PK Challenges) يظهر 3 مقاعد مخصصة أعلى المسرح مجهزة بحدود وتأثيرات تنافسية.
2. **محرك توليد الرمزيات 3D بالذكاء الاصطناعي**:
   - خوارزمية ذكية تحلل الصورة الشخصية للمستخدم لتقوم ببناء خريطة ملامح وتوليد رمزية ثلاثية الأبعاد تفاعلية، مع جعل التوليد الأول مجانياً بالكامل وتكلفة التحديثات اللاحقة 100 عملة مخصومة بشكل ذري من المحفظة.
3. **متجر خزانة الملابس وورشة الحياكة**:
   - تقسيم المقتنيات لـ (إطارات، مركبات، سمات الغرف الملحمية) بأسعار وعملات مزدوجة (ذهب وفضة) لمدد مختلفة (أسبوع، شهر، دائم).
   - ورشة حياكة تفاعلية تحاكي خياطة وتطريز الأقمشة بالذهب والنقوش العربية النادرة (RoyalGold, Arabesque).
4. **فيزياء الهضم والأطعمة التفاعلية (Eating Loop Physics)**:
   - هدايا Cuisines & Beverages المجهزة بفيزياء التلاشي اللحظي وتصاعد الأبخرة والغليان، حيث يتفاعل المستخدم الجالس على الكرسي مع الوجبة ويقل حجم المجسم تدريجياً خلال 30 ثانية.
5. **محاكاة الدخول السينمائية وعاصفة الكوارث الطبيعية**:
   - عروض هبوط أسطورية وزلازل ورعد واهتزاز للشاشة وسقوط هدايا من السقف عند تفعيل السمات النادرة مثل "بوابة الجحيم لملك النار" أو "استيقاظ العملاق الكوني".

## 🛠️ دليل التشغيل والتثبيت السريع (Installation & Setup)

### تشغيل السيرفر الخلفي (FastAPI Backend)

1. **نسخ المستودع وتهيئة بيئة العمل**:
   ```bash
   git clone <repo-url>
   cd Alf-Leila-App
   python -m venv venv
   source venv/bin/activate  # في الويندوز: venv\Scripts\activate
   ```

2. **تثبيت الاعتماديات والمكتبات**:
   ```bash
   pip install -r requirements.txt
   ```

3. **تهيئة ملف متغيرات البيئة**:
   قم بإنشاء ملف `.env` في المسار الرئيسي للمشروع وانسخ الإعدادات من `.env.example` مع تعبئة بيانات الاتصال بـ Supabase و Agora RTC:
   ```bash
   cp .env.example .env
   ```

4. **تشغيل السيرفر**:
   ```bash
   uvicorn main:app --reload --port 8000
   ```
   تصفح واجهة توثيق الـ API التفاعلية عبر الرابط: `http://localhost:8000/docs`.

### تشغيل واجهات الفلاتر (Flutter Frontend)

1. **الدخول لمجلد الفلاتر وتنزيل الحزم**:
   ```bash
   cd frontend
   flutter pub get
   ```

2. **تشغيل التطبيق**:
   ```bash
   flutter run
   ```

## 🎨 جدول الامتيازات ومستويات ترقية الغرف (Privileges Grid)

يحتوي التطبيق على نظام مستويات تقدم شامل للغرف من المستوى 1 إلى 10، ويفتح الامتيازات تدريجياً:
- **Lv.1**: علامة الغرفة، حد الأعضاء، حد المشرفين، خلفية البطاقة، مقاعد فريق PK.
- **Lv.2**: وضع الدردشة العامة المشروط (لحماية الأعضاء)، مقاعد الدردشة المتدرجة، وضع الفيلم وبث الفيديوهات.
- **Lv.3**: وضع الميكروفون المشروط، ترقية البث عالي النقاء، وضع القرص الدوار والألعاب الترفيهية.
- **Lv.4**: وضع دخول الغرفة المشروط (للنخبة والنبلاء فقط)، إطار قائمة الغرفة الفاخر.
- **Lv.5**: وضع عيد الميلاد، سمة وموضوع مخصص للغرفة.
- **Lv.6**: مكافأة العملة الفضية المجانية، وضع زفاف الليالي الأسطوري.
- **Lv.7**: غطاء غرفة بصيغة GIF متحركة، وضع السفر والرحلات.
- **Lv.8**: جلود المقاعد الفريدة، خلفيات قائمة الغرفة المخصصة.
- **Lv.9**: مقعد السوبر الذهبي، المعرف الملون للغرفة (Colored Room ID).
- **Lv.10**: الميدالية الملحمية وصاحب العرش الملكي.

## 🔒 السياسات الأمنية والحماية من الاختراق

- **تشفير كلمات المرور**: استخدام bcrypt لصد هجمات القوة الغاشمة (Brute-force) وهجمات التوقيت.
- **منع الدبل سبند (Anti-Double Spend)**: حماية تامة لعمليات المحفظة عبر أقفال `asyncio.Lock` تمنع الصفقات المتوازية المتزامنة من خصم رصيد غير موجود.
- **حماية البيانات السيرفرية (Error Leaks Prevention)**: اعتراض كافة الاستثناءات البرمجية وتغليفها برسائل خطأ مخصصة دون تسريب تفاصيل لغة بايثون أو السيرفر للعامة.
